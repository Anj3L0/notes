NOTESARCHIVE WEBSITE

Files:
- index.html
- style.css
- script.js

Open index.html in a browser. No server or database is required.

Included screens/interactions based on the provided mobile prototype:
1. Welcome / Splash
2. Sign Up
3. Log In
4. Dashboard
5. Select Subject
6. Create Note
7. My Notes
8. View Note
9. Edit Note
10. Organize by Subject
11. Profile
12. Return to Dashboard

Notes are stored in browser localStorage so creating, editing, and deleting notes works after refreshing the page.
